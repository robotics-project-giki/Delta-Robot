# Delta Robot with Computer Vision

## Overview
An automated Delta Robot system that uses
computer vision to detect, locate and sort
objects using a robotic pick-and-place mechanism.

## System Architecture
Camera → YOLOv8 → OpenCV → Homography
→ ROS 2 → Arduino → Delta Robot

## Features
- YOLOv8 object detection
- Camera-based object localization
- Image-to-world coordinate transformation
- Automated pick-and-place
- Arduino motor control
- ROS 2 communication

## Hardware
- Raspberry Pi 4 (4GB)
- Camera
- Arduino
- Stepper motors
- Motor drivers
- Delta Robot mechanical assembly

## Software

- YOLOv8
